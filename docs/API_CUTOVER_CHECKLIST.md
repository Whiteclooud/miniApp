# API Cutover Checklist（Archived）

## 状态

截至 2026-03-24，`apps/api` 已完成页面验收并成为当前唯一后端基线。

因此本文件所服务的“前端从 `apps/server` 切到 `apps/api` 的切流前检查清单”已经完成使命，**不再作为当前执行清单使用**。

## 为什么归档

本文件属于“并行切流阶段”的过渡文档，核心前提包括：
- `apps/server` 仍作为旧默认基线
- `apps/api` 仍处于切流前验证阶段
- 前端仍需要在两套后端之间做受控切换

这些前提当前都已失效。

继续沿用本文件会造成两类误导：
1. 误以为项目仍处于双基线并行阶段
2. 误以为当前首要工作仍是切流，而不是新基线收口、页面验收与旧基线退场
