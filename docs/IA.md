# IA

## 页面信息架构（V1）

本项目采用“顾客端 + 店员端同一小程序”方案。

---

## 一、角色视图

### 1. 顾客端
- 首页 `pages/home`
- 预约页 `pages/booking`
- 我的预约 `pages/my-bookings`
- 我的灵感 `pages/my-inspirations`

### 2. 店员端
- 规则配置 `pages/staff/rules`
- 预约审核 `pages/staff/appointments`

---

## 二、页面层级

### A. 顾客端

#### 1. 首页 `pages/home`
目标：建立品牌感、展示返图案例、引导预约。

页面模块建议顺序：
1. 顶部品牌欢迎区
   - 门店名称 / slogan
   - 一句简短品牌介绍
   - 主按钮：顾客立即预约
   - 次按钮：店员管理入口
2. 返图展示区
   - 3~6 张返图卡片
   - 支持横向滑动或瀑布/双列卡片
3. 门店服务说明区
   - 预约规则简述
   - 单员工 / 审批制提示可弱化展示
4. 底部 CTA 区
   - 再次强调“立即预约”
   - 次入口：查看我的预约

#### 2. 预约页 `pages/booking`
目标：让顾客在低干扰下完成预约申请。

页面模块建议顺序：
1. 顶部说明
   - 当前是“提交申请，待店员审核”
2. 日期选择区
   - 月视图 / 日期列表
   - 不可预约日期置灰
3. 时间段选择区
   - 展示当天可预约 slot
   - 不可选时段不显示或置灰
4. 联系信息表单
   - 当前微信身份自动识别（OpenID，不手填）
   - 姓名（可选）
   - 手机号（可选）
   - 备注（可选）
5. 提交按钮
   - 文案：提交预约申请

#### 3. 我的预约 `pages/my-bookings`
目标：顾客查看自己的预约状态。

页面模块建议顺序：
1. 查询条件区
   - 使用当前微信身份（OpenID）自动查询
   - 开发环境可展示“身份来源/模拟值”提示
2. 预约记录列表
   - 日期
   - 时间段
   - 状态标签
   - 备注 / 审核备注（若有）
3. 空态 / 异常态

#### 4. 我的灵感 `pages/my-inspirations`
目标：顾客保存、查看并维护喜欢的返图。

页面模块建议顺序：
1. 当前顾客身份与开发环境提示
2. 已保存返图列表与分页加载
3. 返图下线后的失效空态
4. 灵感详情、备注编辑与删除

---

### B. 店员端

#### 4. 规则配置 `pages/staff/rules`
目标：店员维护预约开放规则。

页面模块建议顺序：
1. 提前开放天数
2. 本月不可预约日期
3. 每日可预约时间段列表
4. 增加时间段按钮
5. 保存按钮

#### 5. 预约审核 `pages/staff/appointments`
目标：处理顾客预约申请。

页面模块建议顺序：
1. 顶部筛选区
   - 默认 `pending`
   - 已审核筛选可后补
2. 预约卡片列表
   - 顾客姓名
   - 手机号
   - 预约日期
   - 时间段
   - 备注
   - 当前状态
3. 操作区
   - 通过
   - 拒绝
   - 可选：审核备注

## 三、关键跳转关系

### 顾客主路径
- `home -> booking`
- `home -> my-bookings`
- `booking -> 提交成功态 / my-bookings`

### 店员主路径
- `staff/rules <-> staff/appointments`

---

## 四、导航建议

### 顾客端导航
V1 建议用轻量导航：
- 首页
- 我的预约

预约页通过首页 CTA 进入，不强制放 tab。

### 店员端导航
不建议暴露为普通 tab。
建议：
- 通过专用 staff 入口进入
- 进入后在店员页内部切换“规则配置 / 预约审核”

---

## 五、页面状态设计原则

### 顾客端
- 优先温和、明确、低打扰
- 表单校验提示直白
- 审批制文案要提前说明，避免顾客误以为已成功预约

### 店员端
- 优先清晰、效率、信息完整
- 操作按钮要明确区分“通过 / 拒绝”
- 冲突场景要有即时反馈

- 会员中心

## 七、后续扩展预留

未来若加入商品售卖（手串、咖啡），建议新增：
- `pages/shop/list`
- `pages/shop/detail`
- `pages/orders`

但 V1 首页信息架构不要提前被商品区占满，返图展示与预约转化仍是主目标。
