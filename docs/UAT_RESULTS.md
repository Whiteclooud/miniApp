## 当前建议验收范围（本轮体验优化完成后）

本轮页面级 UAT 优先确认以下 7 条链路：

1. 首页返图灵感仅展示最近 3 条，并提供“查看全部”入口
2. 全部返图列表页展示全部已发布返图，并支持进入详情多图
3. 顾客预约页使用月历组件选择日期，并能看懂日期状态
4. 顾客提交预约与“我的预约”回查不回退
5. 店员可上传图片并创建 / 编辑返图内容
6. 店员可修改已审核预约结果（通过改拒绝、拒绝改通过）
7. 修改审核结果后，顾客侧回查与可约状态保持一致

可选补充项：
- 无权限店员访问返图管理页
- Network 面板接口口径防回退检查
